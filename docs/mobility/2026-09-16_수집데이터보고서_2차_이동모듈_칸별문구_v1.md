## 2.3 흐름도 설명 — 문단 끝에 추가

> 이동 모듈은 수집(공공 API·파일) → 정규화(시각을 분 단위 정수로, 행선지를 열차 단위로 복원, 역명 표기 통일) → 소스 간 정합성 검사 6종 → SQLite 적재 → 판정기 조회 순이다. 벡터 색인은 두지 않는다. 정확한 값 조회이지 의미 검색이 아니고, 색인을 두면 「없다」가 「비슷한 것」으로 바뀌기 때문이다. 이 결정은 2026-09-16 ML 분류기 대조 실험(근거없음 376건 전부 확정답으로 전환)으로 검증했다.
