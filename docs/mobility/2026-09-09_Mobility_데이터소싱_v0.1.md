# Mobility(이동·동선) 모듈 데이터 소싱 v0.1

작성일: 2026년 9월 9일 · 담당: 서유현

Mobility 모듈이 판정에 쓰는 데이터를 소스별로 정리한 문서다. 무엇을 어느 단계에서 쓰는지, 저장해도 되는지, 코어 계약의 `Evidence`에 어떻게 실리는지를 적는다. 확보 상태는 2026-09-09 기준이고, 수치 중 근거가 없는 것은 [추정]으로 표시했다. 설계서 v0.2 8절의 표를 이 문서가 대신하며, 설계서는 이 문서를 참조한다.

## 1 원칙

- **저장은 시간표·규칙 표·우리 판정 이력뿐이다.** 경로 API 응답은 처리 중 메모리에서만 쓰고 저장·캐시하지 않는다(카카오 약관).
- **저장하는 행에는 수집 시각과 소스 이름이 반드시 붙는다.** 코어 `Evidence`가 `source_type · source_id · observed_at`을 의무로 요구하고, 시간표 근거의 `observed_at`은 판정 시각이 아니라 **그 시간표를 받은 시각**이어야 하기 때문이다.
- **성립 여부는 시간표로 끝내고, 외부 호출은 경로 모양이 필요할 때만 한다.** 쿼터·비용·약관 위험을 같이 줄인다.
- 시간표대로 오는 차는 없으므로 시간표는 "기록"으로만 확정이다. 소요·도착 시각은 항상 추정이고 버퍼가 오차를 흡수한다.

## 3 소스별 상세

### 3-1 TAGO 지하철정보 — 시간표 단일 소스 (9/9 수집 완료, 보정 진행 중)

- 오퍼레이션: `GetKwrdFndSubwaySttnList`(역명 → 역 ID, 노선별로 ID가 따로 나옴), `GetSubwaySttnAcctoSchdulList`(역 ID × 요일 01/02/03 × 방향 U/D).
- 응답 특징: `depTime`은 `HHMMSS` 또는 `'0'`(시·종착, 3.6%), 행선지(`endSubwayStationNm`)는 있을 때만. 검색 응답의 역명 키는 `subwayStationName`, 시간표 응답은 `subwayStationNm`으로 **다르다**.
- 수집 결과(9/9): 역명 655개 → 역 ID 713개, 조합 4,278개 완료, 행 384,593개. 확인된 특성 네 가지:
  1. **토요일(02)이 비어 있다.** 수도권 노선은 토·일·공휴일을 03으로 준다(우이신설만 02 별도, 부산 등은 02 있음). 판정기는 토요일 = holiday로 본다 [추정 — 서울교통공사 공식 시간표가 평일/토·공휴일 2종인 것과 일치].
  2. **2·7호선 휴일(03)이 통째로 없다.** 열린데이터광장 `SearchSTNTimeTableByIDService`(휴일 태그 3)로 보충 수집(`seoul_fill_holiday.py`, 34,387행). 통합 시간표에서는 `source=seoul_opendata_OA-101`로 구분.
  3. **동명 역 충돌.** 노선명이 "1호선"처럼 도시 없이 오므로 부산·대구·대전·광주 역(교대·중앙·시청·증산 …)이 같이 잡힌다. ID 접두어(MTRBS/MTRDG/MTRDJ/MTRGJ)와 부산 동해선으로 제외(13,979행).
  4. **역명 미매칭 79개.** TAGO 역명은 병기 괄호가 붙어("경복궁(정부서울청사)", "잠실(송파구청)", "총신대입구(이수)", 서울→"서울역") v1의 정확 일치에 걸러졌다. 잠실·삼성·경복궁·광화문·동작·회현 등 주요 역 포함 → `tago_fix_unmatched.py`(괄호 앞·괄호 안·별칭 규칙)로 재검색 후 시간표 이어서 수집. 보정표는 `tago_name_map.json`.
- ID 체계: `MTRS1`+역코드(서울교통공사), `MTRKR`(코레일), `MTRARA`(공항철도), `MTRDXD`(신분당), `MTRGXA`(GTX-A) 등.
- 빈 조합 1,666개 중 토요일·수도권 밖을 빼면 약 500개. v1 스크립트가 HTTP 실패도 완료로 넣었으므로 `tago_retry_empty.py`로 한 번 더 받아 "실패"와 "진짜 없음"(경춘선 대부분, 6호선 응암순환 상행 등)을 가른다. 진짜 없음은 판정에서 "근거 없음".
- 통합: `build_timetable_v1.py` → `processed/mobility/timetable_v1.jsonl`(TAGO + 보충, 행마다 `fetched_at`(수집일, precision=day)·`source`, 열린데이터광장 `station_cd`·영문명 연결) + `timetable_v1_coverage.md`(노선별 평일/휴일 커버리지·빈 역). 현재 405k행, 공항철도·인천1·2호선 100%, 서울 1~9호선 평일 78~97% (보정 전).
- 예상 호출량: 보정·재시도 합쳐 약 1,500회 [추정]. 갱신은 시간표 개정(분기~반기) 단위로 재수집, `fetched_at` 30일 초과 시 warning(5절).

### 3-2 서울 열린데이터광장 — 역 참조 데이터와 교차검증

역 목록(OA-15442)은 역코드·외부코드·영문/중문/일문 역명을 가져 링크의 장소명(영문 출력)과 노선 매핑에 쓴다. 첫차막차(OA-15492)는 2·3·5~9호선만 있어 판정 근거로 쓰지 않고, TAGO 시간표에서 뽑은 첫차·막차와 대조하는 검증용이다. 시간표(OA-101)는 TAGO가 전 노선을 덮으므로 수집하지 않는다.

### 3-3 카카오 경로 — 호출만, 저장 없음

- 대중교통·도보 경로 REST 각 1,000/일. 출발 시각을 지정할 수 없으므로 "그 시각에 성립하는가"는 카카오가 아니라 시간표가 답한다. 카카오는 **경로 모양**(어느 노선·환승 몇 번·도보 몇 m·대략 몇 분)만 준다.
- 호출 지점 3곳: 최초 검증(구간당 1회), 수정·사건(영향 구간 × 후보), 재확인에서 경로가 바뀌어야 할 때. 여행당 30~60회 [추정].
- 저장 금지 → `Evidence.value`에는 응답 원값이 아니라 판정에 필요한 **파생값**만 넣는다: 성립 여부, 이용 노선명, 환승 횟수, 도보 거리 구간(예: "500~800m"), 추정 소요 5분 단위, 도착 추정 구간. 정류장 목록·경로 좌표·요금·소요 원값은 넣지 않는다. 카카오맵 링크는 우리가 장소명+좌표로 조립하므로 호출이 없다.
- 호출 실패 시: 시간표만으로 성립 여부는 내고 소요·환승은 "판단 불가"로 표시한다. 정상으로 바꾸지 않는다.

### 3-4 규칙 표 — `policy` 근거

환승 여유 5분, 기본 버퍼 10분, 진행 중 버퍼 15분, 유아·짐 동반 도보 상한 800m, 환승 상한 2회(피로도 높음 1회), 후보 열거 순서 ⓐ→ⓓ. 규칙 파일에 버전과 개정일을 두고 `Evidence(source_type="policy", source_id="mobility_rules@v0.1", observed_at=개정일)`로 판정에 붙인다. 합성 여행으로 돌려 조정한다.

## 5 담당 결정과 이유

| 결정 | 이유 |
|---|---|
| 시간표 단일 소스 = TAGO | 열린데이터광장은 1·4호선·공항철도가 없다. 인바운드 여행의 양 끝(공항철도·1호선 서울역)이 빠지면 가장 중요한 구간이 "근거 없음"이 된다. 열린데이터광장은 역 참조·교차검증으로만 남긴다 |
| `fetched_at`은 수집일 정밀도 | v1 수집 스크립트가 행 단위 호출 시각을 남기지 않았다. 시간표 개정은 일 단위보다 훨씬 드물어 판정 근거로 충분하고, `precision=day`를 함께 적어 정직하게 표시한다. 재시도·보정 수집분은 행 단위 시각을 남긴다 |
| 토요일 = 휴일 시간표 | TAGO 수도권 02가 비어 있고 운영사 공식 시간표가 평일/토·공휴일 2종. 별도 토요일 시간표가 확인되면 그때 분리 |
| 2·7호선 휴일은 열린데이터광장으로 보충 | TAGO에 없다. 같은 통합 스키마에 `source`만 다르게 실어 판정기는 소스를 구분하지 않고 Evidence.source_id만 달라진다 |
| 수도권 밖 운영사 행 제외 | 서울 1도시 범위. 동명 역이 섞이면 막차 판정이 다른 도시 시간표로 나갈 수 있다 |
| 카카오 근거는 파생값만 | 약관(응답 저장·캐시 금지)과 에이전트가 제3자인지 회색이다. 판정에 필요한 요약값은 우리 판정의 일부이고, 원값은 남기지 않는다 |
| 시간표 30일 초과 시 warning | "확인 시각"이 오래된 근거로 확정을 말하지 않기 위해. 재수집 트리거이지 판정 불가는 아니다 |
| 버스·리무진은 "근거 없음"으로 시작 | 소스가 없는 구간을 정상으로 바꾸지 않는다는 원칙. 근거 없음 반환이 시연에서도 정직성 장면이 된다 |
