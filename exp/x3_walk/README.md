## 정한 것 (이유)

- **새 그래프를 만들지 않는다** — 발표 코드가 이미 걸음 그래프를 싣고 있다. 그래프가 둘이 되면 어느 쪽이 정본인지부터 다시 정해야 한다.
- **독립 계산기를 따로 둔다** — 발표 코드 길찾기로만 재면 길찾기의 오류와 그래프의 오류를 가를 수 없다. 다른 구현으로 300/300 같은 값이 나왔으므로 아래 어긋남은 **그래프(와 붙이는 규칙) 쪽**이다.
- **카카오는 화면에서 「최단거리」 숫자만 읽는다** — API 를 쓰지 않고 경로를 저장하지 않는다. 숫자 표(`kakao_sample.json`)는 저장소 밖.
- **실측 태그 여정(개인 동선)의 이름이 든 표는 저장소 밖에만** — 요약 숫자에는 이름을 뺐다.
- **변형판은 실험 자료다** — 발표 코드가 읽지 않는다. 광장을 가로지르는 선은 「진입점끼리 면 안에서 직선」으로 단순하게 만들었다(면 안 장애물은 구멍만 본다).
