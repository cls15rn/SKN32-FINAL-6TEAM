## 1. 결론

- **항목 3 — 「전체 자동 추천」 위치**: `[2026-10-15 사용자 지시 · 화면 캡처]` 계획 확인 · 수정 모드에서 목록 위 따로 한 줄이던 「✨ 전체 자동 추천」(잠긴 일정이 있으면 「전체 잠금 해제」도)을 **첫 날짜 제목 줄(「1일차 10.16 금」)의 오른쪽 끝**으로 옮겼다(`plan-rows.tsx` `DayList` 의 `tools` · `plan-check.tsx`). 일정이 하나도 없는 계획은 날짜 줄이 없어 단추도 없다(고칠 것이 없다).
- **항목 4 — 검증 화면 일정 줄을 시간 길이로**: `[2026-10-15 사용자 결정 — ①]` 계획 확인 · 수정 모드의 줄을 다시 **시간 비례(1분 = 1.2px)** 로 — 머무는 시간 실선 · 기다림 · 이동 점선 · 도착 뒤 여유가 모두 분 × 1.2px, 카드는 내용 높이(시간보다 긴 카드 자리는 가는 선), 끝 시각 없는 그날 마지막 일정은 60px 흐린 줄. 10-13 첫 판(`23b5af7b`)의 계산을 `RailList` 의 선택(`toScale`)으로 되살렸고, **여행 화면은 ② 일정한 간격 그대로**(`RAIL_GAP` · 접힌 카드 높이 통일).
  - `[2026-10-15 사용자 지적 · 캡처]` 수정 모드에서 일정 추가 ＋ 와 그 선이 이동 줄(펼친 이동 상자) 머리 위에 겹쳤다 — 일정 사이 ＋ 가 높이 0 으로 경계에 걸려 있었고, ① 에서는 이동 줄이 앞 일정 줄의 빈자리(그 일정의 시간)를 자기 글자 자리로 빌려 경계에 붙었다. 고침: ① 에서는 그 빈자리를 빌리지 않고(`rail-list.tsx` `room`), **일정 사이 ＋ 마다 자기 칸 28px**(`plan-check.module.css` `.insertPoint`) — 카드 · 줄이 늘면 ＋ 칸도 그만큼 아래로 밀린다. 계획 확인 화면에도 같다(여행 화면에는 ＋ 가 없다).
- **항목 5 — 「지금 HH:MM」 꼬리표 + 운영자 스위치**: `[2026-10-15 사용자 결정]` 10-13 에 뺐던 빨간 알약 「지금 10:40」을 여행 화면 「지금」 점 옆에 되살렸다. 시험 기간이라 **기본 켜짐**, 배포 때 관리 콘솔 「운영 설정」 에서 끈다. 끄면 꼬리표만 숨고 점 · 채워지는 줄은 그대로. `[2026-10-15 사용자 지시]` 수정 모드 목록에도 같은 스위치로 꼬리표가 붙는다(`trip-edit.tsx`). 서버는 오늘 들어온 「택시 호출 상품」 스위치와 같은 짜임으로 만들었다(사용자 결정 「백엔드도 같이」).

로컬 실서버(서버 8043 · 웹 127.0.0.1:3111 · DB `acop_web_trip_screen`, 375px):
- 수정 모드: 「1일차 10.16 금」 오른쪽 끝에 「전체 자동 추천」(사용자 캡처와 같은 자리).
- 수정 모드 줄 길이: 경복궁 120분 실선 **144px** · 지하철 22분 점선 **26px** · 도착 뒤 8분 **10px** · 광장시장 60분 **72px** · 인사동 90분 **108px**(모두 분 × 1.2). 여행 화면은 ② 그대로(실선 77px = 카드 끝 · 이동 36px).
- 여행 화면: 오늘(10-15 00:30~02:00) 일정이 든 시험 여행에서 빨간 점 옆 「지금 01:06」. 등록 응답 · 조회 응답 `now_label: true`.
- ＋ 칸(수정 모드 · 이동 상자 펼침): 경복궁 줄 48~184 → ＋ 칸 184~212 → 펼친 이동 273px 212~485 → ＋ 칸 484~512 → 다음 일정 512. 고치기 전에는 ＋ 칸이 0 이라 이동 상자가 184 에서 바로 시작해 ＋ 가 그 머리 위에 있었다. 웹 단위 59 파일 531/531.

**확인하지 못한 것 · 본 것**
- **관리앱 화면에서 스위치를 직접 끄고 켜 보지 않았다**(관리앱을 띄우지 않음) — 관리 콘솔이 그리는 목록 API(`/admin/limits`)는 통합 시험으로 확인.
- 화면에서 끔 상태(점만)는 보지 않았다 — 서버 · 웹 시험으로 확인.
- 지금 시각이 일정 중간이면 꼬리표가 왼쪽 시간 칸의 「~끝」 글자를 가린다(10-13 이전에도 있던 겹침, 시험 기간 표시라 그대로 둠).
- 개발 서버가 코드를 바꿔 끼울 때(빠른 새로 고침) `useEffect` 의존성 크기 경고가 한 번 났다 — 새로 고침 뒤 없음(실행 결함 아님).
- `check` · `test:live` 는 돌리지 않았다(PR 직전에 몰아서).
